# Тензорный калькулятор

[![build](https://github.com/stepkhop/tensor-calculator/actions/workflows/build.yml/badge.svg)](https://github.com/stepkhop/tensor-calculator/actions/workflows/build.yml)

Калькулятор тензорной алгебры с точной арифметикой и графикой.
Python, tkinter, matplotlib.

![Окно калькулятора](docs/screenshot.png)

## Возможности

- Тензоры произвольного типа `(p, q)` при любой размерности `n`.
- Арифметика в обыкновенных дробях (`fractions.Fraction`), без округлений.
- Произведения, перестановки индексов, симметрирование, альтернирование,
  свертки, в том числе двух тензоров разных рангов.
- Для ранга 2: инварианты, корни характеристического уравнения с точными
  кратностями, базисы характеристических пространств, шаровая часть, девиатор.
- Косоугольный базис, поднятие и опускание индексов с метрикой.
- Графика: характеристические пространства, срезы тензоров высших рангов.

## Установка и запуск

### Windows

Готовый `TensorCalculator-Windows.exe` лежит на странице Releases, Python
для него не нужен.

Из исходников:

1. Поставить Python 3.10 или новее с [python.org](https://www.python.org/downloads/),
   отметив «Add python.exe to PATH» и оставив флажок «tcl/tk and IDLE».
2. Скачать репозиторий: Code, Download ZIP, распаковать.
3. Запустить `run.bat`.

Первый запуск занимает около минуты: создается окружение `.venv` и ставится
matplotlib, для этого нужен интернет.

### Linux, macOS

```
./run.sh
```

или вручную:

```
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python main.py
```

## Использование

Слева вводится тензор `A`, справа `B`. Для каждого задаются `p`, `q`, `n`,
затем нажимается «Создать поля». Вводятся компоненты в текущем базисе: сначала
верхние индексы `i1..ip`, затем нижние `j1..jq`. У тензора ранга 2 поля
образуют обычную матрицу, у тензоров выше два последних индекса дают матрицу,
остальные нумеруют блоки. В ячейке допустима дробь (`1/3`, `-5/2`), пустая
ячейка считается нулем.

Тип `(p, q)` хранится вместе с компонентами и определяет допустимые операции:
складываются только тензоры одного типа, свертка идет по паре верхний -
нижний индекс.

Базис задается в поле справа векторами `e_i` в декартовых координатах, по ним
считается фундаментальная матрица `g_ij = (e_i, e_j)`. Именно векторы, а не
матрица: при повороте базиса `g_ij` не меняется, поэтому по ней нельзя
построить рисунок. По умолчанию базис декартов ортонормированный.

Выражение вводится в строке «Выражение» и считается по Enter. Кнопка
«Собственные значения» выводит инварианты, корни, кратности и базисы ХП;
рациональные корни выводятся точно, корни квадратного множителя в радикалах
(`2 ± i√14`). Список «Пример...» заполняет `A` готовыми тензорами.

## Выражения

| Запись | Смысл |
|---|---|
| `A + B`, `A - B`, `-A` | сложение, вычитание (типы должны совпадать) |
| `A * B` | тензорное произведение; `2 * A` - умножение на число |
| `A / 3` | деление на число |
| `A ^ B`, `wedge(A, B)` | внешнее произведение (по верхним индексам, у ковекторов по нижним); у `^` в Python приоритет ниже `+` и `*`, надежнее `wedge` |
| `dot(A, B)` | однократная свертка: `A^i_j B^j_k`, `A^i_j v^j` |
| `ddot(A, B)` | двойная свертка: `C^{ij}_{kl} e^{kl}` |
| `contract(T, i, j)` | свертка i-го нижнего индекса с j-м верхним |
| `contract2(A, B, 'p', i, j)` | i-й верхний индекс A с j-м нижним B (`'q'` наоборот) |
| `contract2(A, B, [('p', i, j), ('q', k, l)])` | свертка по нескольким парам |
| `tr(T)`, `det(T)` | след (тип (1,1)) и определитель (ранг 2) |
| `sym(T)`, `alt(T)`, `symq`, `altq` | симметрирование, альтернирование верхних (нижних) осей |
| `perm(T, [2,1,3])`, `permq` | перестановка верхних (нижних) осей |
| `dev(T)`, `sph(T)` | девиатор и шаровая часть |
| `delta(n)`, `eps(n)` | символ Кронекера и символ Леви-Чивиты |
| `low(T, i)`, `up(T, i)` | опустить i-й верхний, поднять i-й нижний индекс матрицей G |
| `low(T, i, B)`, `up(T, i, B)` | то же с метрикой B (тензор ранга 2) |
| `G`, `E` | фундаментальная матрица `g_ij` и обратная к ней `g^ij` |

Оси нумеруются с единицы, отдельно в каждой группе. Строка разбирается модулем
`ast`, произвольный код через нее не выполняется. Результат ограничен 6561
компонентой, симметрирование - семью осями.

## Графика

| Тензор | Изображение |
|---|---|
| ранг 0 | число |
| ранг 1, n = 2, 3 | стрелка |
| ранг 2, n = 3 | характеристические пространства: прямая, плоскость или сфера; комплексные корни выводятся в подписи |
| ранг 2, n = 2 | то же на плоскости |
| ранг 3 и выше | срезы: матрицы n x n по двум последним индексам |

Сцена вращается мышью, флажок «Вращать» включает автоповорот. В косоугольном
базисе рисуются векторы `e_i`, флажок «Рисовать базис» их убирает.

## Тесты

```
pip install pytest
pytest -v
```

В Windows то же самое делает `run_tests.bat`. Всего 84 теста: тензорные
тождества, спектр, разбор выражений, графика.

## Сборка exe

`build_exe.bat` собирает `dist\TensorCalculator.exe` через PyInstaller.
GitHub Actions делает то же самое для Windows, Linux и macOS, по тегу `v*`
файлы попадают в релиз.

## Модули

| Файл | Назначение |
|---|---|
| `recur_tensor.py` | класс `RecurTensor`, хранение компонент |
| `tensor_ext.py` | операции тензорной алгебры, свертки разных рангов |
| `tensor_eigen.py` | характеристический многочлен, корни, ХП |
| `tensor_viz.py` | рисование (matplotlib) |
| `expr.py` | разбор выражений |
| `main.py` | интерфейс (tkinter) |

## Происхождение кода

Класс `RecurTensor` (`recur_tensor.py`) и первая версия операций взяты из
репозитория [avtakhov/tensor](https://github.com/avtakhov/tensor). Слой
операций, собственные значения, графика, разбор выражений, интерфейс и тесты
написаны для курсовой работы по тензорному анализу.
